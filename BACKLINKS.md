# LittleLearners — Off-Page SEO & Backlink Playbook

**Site:** littlelearners.site — UK kids' educational printables (buy-once PDFs, ages 3–6, EYFS/KS1 aligned)
**Positioning line for all outreach:** *"Buy once. Yours forever. No subscription."* — the buy-once alternative to worksheet subscriptions.
**Rules:** 100% white-hat. No link farms, no PBNs, no paid links without `rel="sponsored"`, no automated spam, no spun content. Google's spam policies (confirmed in the May 2026 update round) treat **excessive reciprocal link exchanges** as link spam — so we do NOT run link-swap schemes. What we do instead is in §7.

## 2. Local citations (UK)

For a digital-goods business, citations are about **trust signals and NAP consistency**, not local rankings. Most UK directories accept online-only businesses — choose "online business / no physical premises" where offered.

**NAP (use EXACTLY this everywhere):**
- Name: LittleLearners
- Website: https://littlelearners.site/
- Email: hello@littlelearners.site
- Address: list as "Online only — United Kingdom" (never invent a fake street address; several directories penalise/removes fake addresses)
- Phone: only if you have a real business number — otherwise leave blank consistently

**Worth listing (verified as accepting online businesses / free tiers):**

| Directory | Notes |
|---|---|
| Yell.com (yell.com) | Free basic listing; strong UK authority |
| FreeIndex (freeindex.co.uk) | Free; review features; accepts online businesses |
| Scoot (scoot.co.uk) | Free listing; UK-focused |
| Thomson Local (thomsonlocal.com) | Long-standing UK directory |
| Cylex UK (cylex-uk.co.uk) | Free signup |
| Hotfrog UK (hotfrog.co.uk) | Free listing |
| Yelp UK (yelp.co.uk) | Accepts online businesses as service-area |
| 192.com | UK directory, free basic |
| Google Business Profile | Possible as a **service-area business** (hide address, verify by postcard/video). Only do this once — duplicates get suspended. |
| Bing Places | Same approach as GBP |
| Trustpilot | Claim the business profile early (even with 0 reviews — it prevents squatting and it's where UK parents check) |

**Rules:** identical NAP everywhere; complete every field (description, category: "Educational supplies"/"Children's bookstore", logo); one listing per directory (no duplicates); write a **unique 2–3 sentence description per directory** — never paste the same paragraph 20 times (duplicate content across citations is the thing that gets directory links discounted).

**Skip:** any directory that demands payment for a basic listing, has no real traffic, or is clearly a link-farm ("1000 free directories" lists). Quality over quantity — 10 good citations beat 100 junk ones.

## 3. Web 2.0 properties

2026 reality check: Web 2.0 links work **only as genuine mini-publications** — real articles, real value, one natural contextual link. Most are `nofollow`; value = referral traffic + brand footprint + topical reinforcement. Thin/spun pages are ignored or worse.

**Build these four (one article each to start, then one per month):**

| Property | Setup |
|---|---|
| **Medium** publication "LittleLearners" | Import-free, original articles; link in author bio + one contextual link per article |
| **WordPress.com** blog (littlelearners.wordpress.com or custom) | 3–4 posts; About page links home |
| **Blogger** (littlelearners.blogspot.com) | 2–3 posts; profile links home |
| **Substack** newsletter | Repurpose guides as newsletter issues; archive pages get indexed |

**Content rules for Web 2.0:** unique articles (never copy from littlelearners.site or from each other), 800–1,200 words, genuinely useful, **different angles from the 12 guides** in TOPICAL_AUTHORITY.md (one intent = one article — no cannibalisation). Link back with natural anchors: "LittleLearners", "our printable packs", or the article-relevant guide URL once it exists.

**Two ready-to-publish drafts are in `content/offpage/`:**
- `web20-article-1.md` — *"I Cancelled Our Worksheet Subscription. Here's What We Do Instead."* (the buy-once angle — Medium)
- `web20-article-2.md` — *"7 Rainy-Day Printable Activities for Ages 3–6 (No Prep Needed)"* (activity angle — WordPress.com/Blogger)

Publish draft 1 in Week 3, draft 2 in Week 5. Write one fresh article per month after that, each mapped to a pillar but a **new** intent.

## 4. Forums & communities

Goal: become a recognised helpful voice. Links come second and only where the community allows them. **Never drop links in a first post.**

**Real targets:**

| Community | Where to participate | Link policy reality |
|---|---|---|
| **Mumsnet** (mumsnet.com/talk) | Talk boards: `/talk/home_ed`, `/talk/primary`, `/talk/behaviour_development` | Strict anti-spam; links only when directly answering a question, never promotional. Build history first. High traffic value even without links (brand searches). |
| **Netmums** forum | Parenting/education sections | Similar to Mumsnet — helpful answers only |
| **r/UKParenting** | Weekly threads, school-readiness questions | No self-promotion; link only if it's the genuinely best answer and sub rules allow |
| **r/Parenting** | Large, strict moderation | Same — value first |
| **r/homeschool** | UK home-ed questions come up | Resource recommendations welcome when relevant |
| **The Student Room** (mature/parents sections) | Occasional early-years threads | Low priority |

**Participation rules (non-negotiable):**
1. Lurk 2 weeks, learn the culture, before posting anything with a link.
2. Answer questions fully **in the post itself** — the link is a footnote ("I wrote a longer guide on this here"), never the answer.
3. One link-bearing post per 10+ pure-value posts.
4. Never post the same answer/link across multiple threads (spam pattern).
5. Disclose affiliation when recommending your own product ("I make these, so biased — but…").

Expected yield: 2–4 earned links + meaningful referral traffic in 90 days. The bigger win is parents citing you elsewhere.

## 7. Link exchanges — the honest position

**Google's spam policies list "excessive link exchanges" as link spam** (confirmed again in the May 2026 policy roundup; John Mueller has said the same for years). Systematic "you link me, I link you" schemes risk manual penalties. **We do not do reciprocal link schemes. Period.**

**The compliant alternative: the /resources partner page.**
- Build `/resources/` on littlelearners.site: a genuinely useful, curated page — "Helpful resources for UK parents of 3–6 year olds" (draft content in `content/offpage/resources-page.md`).
- List ~12 resources across categories (official curriculum info, free learning sites, parenting support) with honest 2-line descriptions. Include competitors' free sections where genuinely useful — that honesty is what makes the page link-worthy.
- **Outreach:** email each listed site once: "We've featured [Site] in our resources roundup for UK parents — thought you'd like to know." No ask for a link. A meaningful fraction link back or share it voluntarily.
- Also submit the /resources page (and the free sample) to 3–4 "free printables" roundup curators.

This earns the *effect* of reciprocal linking (relevant sites linking to each other) with none of the scheme pattern: links are editorial, one-directional, and spread over time.

## 11. Expectations & guardrails (read this twice)

- **No ranking guarantees.** Links are one signal among hundreds. Anyone guaranteeing #1 is lying.
- **Velocity:** new site = slow start is normal and safer. ~2–4 new links/week max in months 1–3.
- **Anchor text:** mostly branded ("LittleLearners") and naked URLs; exact-match commercial anchors ("buy phonics worksheets") under 10% of profile.
- **What actually moves the needle:** 1 link from a real UK parenting blog > 50 directory links. Prioritise accordingly (§6, §8).
- **Measure:** Google Search Console (links report + impressions on guide pages), referral traffic in analytics, brand-search volume. Not third-party "DA" — it's not a Google metric.
- **Maintenance:** monthly — check live links still exist, NAP still consistent, disavow only if you ever see a clear negative-SEO attack (rare; don't disavow speculatively).
